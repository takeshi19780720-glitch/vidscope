## Submission Workflow

1. **Prepare assets**
   - Confirm logo/icon URLs are publicly accessible
   - Upload `og-image.png` or a dedicated screenshot if the platform requires a web URL
   - Prepare a short tagline and 2–3 description lengths

2. **Submit AlternativeTo first**
   - Use Description Variation A or B
   - Link TubeBuddy, vidIQ, Social Blade, and Socialinsider as alternatives
   - Add all relevant feature tags

3. **Submit SaaSHub**
   - Use the SaaSHub tagline + full description
   - Match competitor listings to the same four tools

4. **Prepare Product Hunt for later launch**
   - Do not submit immediately unless the launch plan is ready
   - Build maker profile and gather visuals first

5. **Claim or submit G2**
   - Submit product profile
   - Plan a small outreach campaign to collect 3–5 verified reviews

6. **Track referrals**
   - Add UTM parameters to directory links if possible, e.g. `https://vidscope.app/?utm_source=alternativeto&utm_medium=directory`
   - Monitor Search Console and analytics for new referrer traffic

## Do's and Don'ts

### Do
- Emphasize: free, privacy-first, multilingual, no signup, no channel auth
- Link directly to the English landing page where English-speaking visitors land
- Use the same core message across all directories for consistency
- Keep descriptions factual and benefit-driven

### Don't
- Mention removed features: estimated revenue, engagement rate, or export
- Claim "API key not required" — the app supports user-provided or server-rotated API keys
- Use all-caps or excessive punctuation
- Submit Product Hunt without preparing visuals and community support
